# 수료 후 내 앱 실행·개인 AI 설정·최종 패키지 보관

> 참조 조건: 사용자가 이 문서 또는 수료 후 안내를 명시적으로 참조하라고 요청할 때만 읽고 적용합니다. 일반 질문이나 단계 작업에서 자동으로 읽거나 실행하지 않습니다.
> 이 문서는 모든 단계가 끝난 뒤 프로젝트가 갖추어야 할 실행·설정·보관 기준입니다. 현재 구현 완료나 실행 성공을 뜻하지 않습니다. 원문에 없는 명령 인수·설정 키·모델 ID는 추측하지 않습니다.

수료 후에는 Node.js가 설치된 PC에서 내 누적 프로젝트를 독립 실행합니다. 워크벤치와 학원 계정은 실행에 필요하지 않습니다. 기본 실행과 예제 화면은 미연결 상태로도 사용할 수 있으며, 개인 AI·실제 접근 제어·XDR 연결은 각각 본인의 설정과 이용 권한이 필요합니다.

## 1. 수료용 도구 준비

수료용 도구 묶음을 기존 프로젝트 밖의 새 폴더에 풉니다. 설치 미리보기로 추가할 파일을 확인한 뒤 적용합니다. 기존 학생 코드·제공 서버·Git 기록을 덮어쓰지 않습니다.

## 2. 독립 실행

기존 `on-client` 폴더에서 `tools/start-standalone.ps1`로 실행합니다. 기본은 개인 AI 꺼짐·외부 서버 미연결입니다. `-Demo`는 예제 화면이며 실제 연결이 아닙니다.

## 3. 개인 설정과 키 보관

프로젝트 밖 개인 설정 JSON에서 앱 이름과 사용할 공급자·정확한 모델 ID를 정합니다. 개인 키는 서버 프로세스에서만 입력하며 브라우저·코드·ZIP에 저장하지 않습니다. 포털 이름 저장은 이 파일을 자동 변경하지 않습니다.

## 4. 개인 AI 사용 확인

개인 AI 화면에서 보안 이벤트의 근거·규칙·현재 상태를 확인하고 전송·본인 사용량을 확인한 뒤 설명을 요청합니다. ‘설정됨’은 실제 호출 성공이 아니며, 설명·제안은 조치 실행이나 공식 판정이 아닙니다.

## 5. 최종 패키지 내보내기와 직접 확인

`tools/export-student-package.mjs`로 내가 수정한 프로젝트를 아직 없는 새 폴더에 내보냅니다. `START_HERE.md`와 `FINAL_RELEASE_CHECKLIST.md`를 따라 실행·중지·재시작·누적 기능·기존 자료 보존을 직접 확인합니다.

## 6. 구조 검사 범위

`tools/check-release-readiness.mjs`는 목록·해시·필수 파일을 확인합니다. 이 구조 검사만으로 실제 연결이나 21·22단계 통과가 확인되는 것은 아닙니다.

## 다운로드 안내와 기존 자료 보존

[수료용 도구·상세 설정 안내 받기](https://aleph-workbench-downloads.vercel.app/alekov.html#after-course)

기존 Workbench 설치 ZIP과 13단계 시작 틀은 그대로 유지합니다. 수료용 도구 ZIP에는 학생이 작성한 코드가 없으므로, 최종 앱은 본인의 누적 프로젝트에서 내보내야 합니다.

## 현재 기록

사용자가 제공한 안내를 보관한 문서입니다. 이 문서를 만들면서 도구 다운로드·설치·앱 실행·개인 AI 요청·패키지 생성·구조 검사·제출을 수행하지 않았습니다. 이 문서를 참조할 권한과 실제 설치·외부 요청·제출 등의 실행 권한은 구분합니다.
