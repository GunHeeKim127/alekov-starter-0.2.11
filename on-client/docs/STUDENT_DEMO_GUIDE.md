작성일: 2026-10-27. 관제 대시보드형을 지향하며 포장 없이 PC의 프로젝트 폴더에서 실행합니다. 현재 화면은 요약 카드와 두 시점 비교 방식입니다. 시간 변화 그래프와 지속 수집 기능은 구현하지 않았습니다. 이 문서는 시연 안내이며 전체 기능의 실제 연결 성공이나 공식 통과 증명은 아닙니다.

## 2. 핵심 기능 세 가지 시연

시작할 때 “지금부터 이 PC에서 직접 조회한 값만 보여 드립니다. 조회 전·실패는 수치로 대신하지 않습니다”라고 설명합니다. 아래는 실행할 시연 절차이며 이번 문서 작성에서 전부 실행했다는 뜻은 아닙니다.

| 순서 | 직접 할 일 | 확인할 화면·예상 결과 | 설명할 한계 |
|---|---|---|---|
| 1. PC 자원과 비교 | 5191 화면에서 Tab으로 「PC 자원 다시 조회」 이동 → Enter → 측정 후 한 번 더 조회 | CPU %, 메모리 사용량 GiB, 프로젝트가 있는 볼륨의 남은 공간 GiB와 각각의 측정 시각. 두 번째 조회는 기준과 비교 | 시스템 전체 CPU의 짧은 구간 평균이며 앱 하나의 점유율이 아닙니다. 지속 그래프가 아닙니다. |
| 2. 네트워크·방화벽 | 「네트워크·방화벽 다시 조회」 → 대기 후 상세 펼침 | 읽은 구성·프로필과 조회 시각. 실패한 항목은 확인 불가·이유·다음 행동 | 읽기만 합니다. 조회 성공이 인터넷·SDP 연결 성공이나 안전 판정은 아닙니다. |
| 3. 최근 Windows 기록 | 「최근 기록 다시 조회」 → System·Application별 건수·기간 확인 | 경고·오류를 구분하고 시각·단위 ‘건’을 읽습니다 | 침해나 공격 탐지 결과가 아닙니다. 읽기 실패는 0건이 아닙니다. |

두 Windows 조회 버튼은 같은 조회 경로를 사용해 네트워크·방화벽·최근 기록·SDP 표시를 함께 갱신합니다. 별개 측정 요청이라고 설명하지 않습니다. 펼침 영역은 Tab·Enter로 조작합니다. 조회 중 대기 문구와 버튼 비활성화를 확인합니다.

SDP는 별도 영역에서 확인합니다. 제공 진단의 engine.mode가 disconnected이면 ‘SDP 미연결’, 진단을 못 읽거나 실제 연결을 증명할 수 없으면 ‘SDP 연결 확인 불가’입니다. PC 조회 성공과 섞지 않습니다.

## 3. 실제 값과 예시 값

- 실제 값은 조회 출처·측정 시각·단위를 함께 읽습니다. 값은 재조회하면 달라질 수 있습니다.
- 아래 실제 수치는 관찰 기록이며 화면에 고정할 예시 데이터가 아닙니다.
- 설명용 예시나 모의 입력을 제시한다면 반드시 ‘설명용 예시·실제 조회 아님’으로 별도 표기합니다. 이번 문서에는 모의 수치를 실제 측정값으로 넣지 않았습니다.
- 읽지 못한 값은 ‘확인 불가’와 이유로 남깁니다. 권한을 올리거나 보안 설정을 끄지 않습니다.

## 6. 같은 결과를 다시 확인하는 방법

프로젝트의 `on-client` 폴더, 즉 package.json·student·tools·src가 있는 곳에서 일반 PowerShell을 엽니다. 다른 PC에서는 자기 프로젝트 위치를 사용합니다. 기존 폴더·인증 파일·제출물은 이동하거나 덮어쓰지 않습니다.

```powershell
node --version
Test-Path .\student\pc-status-server.mjs
Test-Path .\student\pc-status.html
Test-Path .\student\pc-windows-status.ps1
```

세 파일이 True인지 확인합니다. 제공 실행 도구의 지원 Node.js 주 버전은 22~24이고 이번 구문·측정 검사는 24.22.1로 했습니다. package.json의 수업 기준 24.19.0과 구분합니다. 현재 선택된 node가 지원 범위 밖이면 본인 PC에 설치된 지원 런타임을 선택합니다. 다른 PC에 작성자의 캐시 경로가 있다고 가정하지 않습니다.

첫 번째 창에서 보안 앱을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

두 번째 창도 같은 앱 폴더에서 열고 PC 상태 서버를 실행합니다.

```powershell
node .\student\pc-status-server.mjs
```

1. 출력된 정상 시작 주소를 확인합니다. 이미 실행 중이면 중복 실행하지 않습니다.
2. 브라우저에서 `http://127.0.0.1:5189/`와 `http://127.0.0.1:5191/`을 엽니다. 서버 시작은 계정 연결 성공이 아닙니다.
3. 5191에서 위 세 기능을 차례대로 직접 조회하고 시각·단위·출처를 확인합니다. Windows 조회는 최대 약 40초가 걸릴 수 있습니다.
4. SDP·확인 불가 항목은 별도로 설명합니다. 공격 재현·권한 상승·유료 AI 반복 요청을 하지 않습니다.
5. 시연 후 각 서버 창에서 Ctrl+C로 종료합니다. 같은 명령으로 재실행할 수 있습니다.
